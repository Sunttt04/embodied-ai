# 术语表（Glossary）

> 每周复盘时往里加几条。32 周后就是一本属于你自己的复习手册。
> 面试前翻一遍，比背任何八股文都管用——因为每个词都对应你真正做过的事。

**格式**：术语 ｜ 一句话解释 ｜ 类比 ｜ 首次出现的周次

## 1. 系统与虚拟化（W01）

| 术语 | 一句话解释 | 类比 | 周 |
|---|---|---|---|
| **虚拟化（VT-x / AMD-V）** | CPU 提供的硬件能力，让一台电脑跑多个"电脑" | 一套房子隔出多个独立房间 | W01 |
| **Hyper-V / 虚拟机平台** | Windows 自带的虚拟化功能层 | 隔断墙和承重结构 | W01 |
| **WSL2** | Windows 里的轻量 Linux 虚拟机，微软深度集成，支持 GPU 直通 | 地下室隔出一间标准厨房 | W01 |
| **发行版（distribution）** | Ubuntu、Debian 等"Linux 品牌" | 不同菜系 | W01 |
| **内核（kernel）** | 操作系统最底层，管硬件和进程 | 厨房的燃气总阀 | W01 |
| **rootfs** | 一个 Linux 系统的全部文件打包 | 整套厨房设备的装箱单 | W01 |
| **Appx / AppxBundle** | 微软的应用安装包格式（类似手机 apk，Bundle 里含多架构） | 平板包装的家具 | W01 |
| **MSI** | Windows 传统安装包格式 | 需要安装师傅上门的家具 | W01 |
| **`wsl --import`** | 把 rootfs 直接注册成发行版，跳过图形安装器 | 自己组装家具，不等师傅 | W01 |
| **GPU 直通（/dev/dxg）** | 虚拟机里能直接调用物理显卡 | 地下室厨房直接接家里燃气管道 | W01 |

## 2. 版本控制（W01）

| 术语 | 一句话解释 | 类比 | 周 |
|---|---|---|---|
| **Git** | 本地版本控制工具，记录每次改动 | 带时间机器的存档系统 | W01 |
| **GitHub** | 托管 Git 仓库的网站（Git 和它是两回事） | 云盘，但只存存档不存原件 | W01 |
| **仓库（repository）** | 一个被 Git 管理的项目目录 | 一个带档案柜的房间 | W01 |
| **commit** | 给当前所有改动拍一张快照，生成唯一编号 | 存档点 / 游戏存盘 | W01 |
| **hash（如 8948c86）** | 由内容算出的指纹，内容变一个字节它就全变 | 文件的身份证号 | W01 |
| **暂存区（staging）** | `git add` 之后、`commit` 之前的缓冲区 | 购物车 | W01 |
| **remote / origin** | 远程仓库的地址 / 默认远程的别名 | 总店的地址 | W01 |
| **push / pull** | 把本地提交推到远程 / 把远程拉回本地 | 上传/下载存档 | W01 |
| **clone** | 把远程仓库连历史一起复制到本地 | 整店复制一份 | W01 |
| **`.gitignore`** | 告诉 Git 哪些文件不要跟踪 | 搬家时的"不要装箱"清单 | W01 |
| **README** | 仓库首页展示的说明文档 | 产品说明书 | W01 |

## 3. Python 与深度学习环境（W01）

| 术语 | 一句话解释 | 类比 | 周 |
|---|---|---|---|
| **conda** | Python 环境与包管理器 | 能装多个独立工具箱的柜子 | W01 |
| **环境（env）** | 一套隔离的 Python + 依赖集合 | 每个项目一个工具箱，互不污染 | W01 |
| **pip** | Python 的包安装工具 | 从仓库提货 | W01 |
| **wheel（.whl）** | 预编译好的 Python 包 | 成品家具，不用自己锯 | W01 |
| **镜像源（mirror）** | 国内对 PyPI / conda 仓库的完整副本 | 本地仓，比海淘快 | W01 |
| **CUDA 驱动** | Windows 侧安装，决定"最高支持哪个 CUDA 版本" | 发动机的油路 | W01 |
| **CUDA 运行时** | 随 PyTorch 一起打包的库 | 变速箱，型号必须和发动机匹配 | W01 |
| **cu126** | 用 CUDA 12.6 编译的版本 | 变速箱型号 | W01 |
| **PyTorch** | 主流深度学习框架 | 做菜的灶台 | W01 |

> **硬约束链**：显卡 → 驱动版本 → 支持的最高 CUDA → 能装哪个 torch。
> 本机 546.30 只到 CUDA 12.3，所以不能装 cu13 的 torch。

## 4. 网络与代理（W01）

| 术语 | 一句话解释 | 类比 | 周 |
|---|---|---|---|
| **代理（proxy）** | 让流量先经过另一台服务器再出去 | 找人代收快递 | W01 |
| **系统代理** | Windows 给图形程序用的代理设置 | 只在客厅生效的改道 | W01 |
| **TUN 模式** | 在网卡层接管全部流量，命令行/管理员程序也走代理 | 全屋改道 | W01 |

| **DNS** | 把域名翻译成 IP 的服务 | 电话簿 | W01 |

| **端口（port）** | 同一台机器上不同服务的门牌号 | 大楼里的房间号 | W01 |
| **SSH** | 加密的远程登录协议 | 带密码锁的专用通道 | W01 |
| **密钥对（公钥/私钥）** | 私钥签名、公钥验证，私钥不出本机 | 印章和印鉴 | W01 |

## 常见误解（踩过才知道）

1. **"Git 和 GitHub 是一回事"** —— 不是。Git 是本地工具，GitHub 是托管网站，没有 GitHub 也能用 Git。
2. **"改 hosts 能解决所有访问问题"** —— 只能解决 DNS 解析错误；如果 IP 被封锁（TCP 连不上），改 hosts 没用。
3. **"装最新版总没错"** —— 深度学习生态里，**版本匹配**比"新"重要得多。
4. **"`pip install` 失败就是网络问题"** —— 也可能是 Python 版本没有对应 wheel（如 3.14 装 torch）。
5. **"报错 `Repository not found` 就是仓库不存在"** —— 也可能是你把用户名/仓库名打错了（少一个字母都算错）。
