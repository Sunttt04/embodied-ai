## 一、总体

| 项 | 值 |
|---|---|
| 周期 | 2026.11 – 2028.11（约 100 周，到秋招） |
| 每周投入 | 10–15 小时（课程周取下限，假期取上限） |
| 主线 | 机器人运动控制 + 强化学习 + 模仿学习 |
| 备线 | VLA（理解 + 跑通，不从零训练） |
| 硬件 | RTX 3060 Laptop 6GB（训练上云）；实验室无真机 |

**为什么不是 52 周**：按内容量估算约 880 小时，52 周 × 12h = 624h，装不下。
按 12h/周算需要约 75 周。**计划不打折，时间放宽。**

## 五、每周节奏

| 时间 | 内容 |
|---|---|
| 周一–周四 | 每天 1.5–2h：先讲后敲，当堂跑通 |
| 周五 | 缓冲（补欠账 / 休息） |
| 周六 | 2–2.5h：整块攻坚，产出交付物 |
| 周日 | 休息（最多花 15 分钟写日志） |

**中断恢复协议**（隔了 3 天以上回来时用）：

1. 不看资料，先答 3 个自测题（5 分钟）
2. 跑一个旧脚本，确认环境没坏（5 分钟）
3. 看本周任务，直接开始（5 分钟）

## 六、验收规则

**每个阶段项目必须有一个数字**，写进 README：

| 项目 | 至少要有 |
|---|---|
| 二连杆仿真 | 末端位置误差 < 1e-6 |
| PID 跟踪 | 稳态误差、超调量 |
| PPO 训练 | 回报曲线、训练步数、成功率 |
| 模仿学习 | 成功率、与 BC 基线对比 |
| VLA 推理 | 成功率、推理延迟(ms) |

**没有数字的项目，秋招时讲不出深度。**
